### 3.6 L6 手动功能测试 (Manual QA) — 详细步骤 + 自动化状态

#### M-01: 启动游戏
- **操作**: 在终端中运行 `python3 main.py`
- **预期**: 显示彩色主菜单，包含游戏列表 (1-7)、操作说明
- **验收标准**: 
  1. 终端输出包含 "脑力训练" 或 "Brain Games" 字样
  2. 显示至少 7 个游戏选项
  3. 包含难度选择提示
  4. 程序不崩溃，等待用户输入
- **自动化**: ✅ 已通过 test_engine.py + test_e2e_user_flow.py 覆盖

#### M-02: 难度选择
- **操作**: 输入 `1` 进入记忆迷宫，然后输入 `e` (简单)、`n` (普通)、`h` (困难)
- **预期**: 进入对应难度的游戏，难度影响迷宫大小/记忆时间等
- **验收标准**:
  1. 输入 `e` → 迷宫 5×5，记忆时间 15 秒
  2. 输入 `n` → 迷宫 8×8，记忆时间 10 秒
  3. 输入 `h` → 迷宫 12×12，记忆时间 5 秒
  4. 输入无效字符 → 提示重新输入
- **自动化**: ✅ 已通过 test_game_interaction.py (test_all_difficulties) 覆盖

#### M-03: 无效输入处理
- **操作**: 在主菜单输入 `a`, `z`, `!`, `@`, `0`, `8` 等非选项字符
- **预期**: 程序不崩溃，不退出，继续等待有效输入
- **验收标准**:
  1. 输入 `a` → 无反应或提示无效，不退出
  2. 输入 `!` → 同上
  3. 输入 `0` → 同上 (无效选项)
  4. 输入 `8` → 同上 (超过 7)
  5. 连续输入 100 个无效字符 → 不崩溃
- **自动化**: ✅ 已通过 test_edge_cases.py + test_game_interaction.py 覆盖

#### M-04: 记忆迷宫 — 记忆阶段
- **操作**: 启动记忆迷宫简单难度，观察记忆阶段 15 秒
- **预期**: 显示完整迷宫布局，倒计时进度条递减
- **验收标准**:
  1. 迷宫有明确的起点 `S` 和终点 `E`
  2. 墙壁用 `█` 表示，通道用 `·` 表示
  3. 倒计时进度条从 100% 递减到 0%
  4. 记忆阶段不接受移动输入 (WASD)
  5. 15 秒后迷宫消失，进入行走阶段
- **自动化**: ✅ 已通过 test_game_interaction.py (test_initial_state) 覆盖

#### M-05: 记忆迷宫 — 行走阶段
- **操作**: 迷宫消失后，使用 WASD 移动
- **预期**: `@` 代表玩家，移动后留下 `*` 轨迹
- **验收标准**:
  1. 按 `w` → 向上移动一格
  2. 按 `a` → 向左移动一格
  3. 按 `s` → 向下移动一格
  4. 按 `d` → 向右移动一格
  5. 移动轨迹用 `*` 标记
  6. 到达终点 `E` → 游戏结束，显示结算
- **自动化**: ✅ 已通过 test_game_interaction.py (test_move_no_collision) 覆盖
