## 变更记录 (CHANGELOG)

### v2.0.0 — 2026-05-12

**新增功能**:
- Web 版 GUI：HTML5 Canvas 图形界面，浏览器直接运行
- 7 款游戏全部使用 Canvas/DOM 重新实现
- 深色主题 + 霓虹配色
- Web 服务器支持分数 API (GET/POST)
- 与终端版共享分数文件

### v1.0.0 — 2026-05-10

**新增功能**:
- 7 款脑力训练游戏全部实现
- 主菜单 + 难度选择 + 最高分系统
- 三档难度（简单/普通/困难）
- 分数持久化（JSON）
- 跨平台支持（Linux/macOS/Windows）
- 彩色/无彩色终端自适应

**游戏列表**:
1. 记忆迷宫 — 空间记忆训练
2. 弹幕大脑 — 快速计算+反应
3. 密码破译 — 逻辑推理训练
4. 节奏大师 — 节奏感训练
5. 打地鼠 — 视觉搜索+反应速度
6. 故事解谜 — 综合脑力+阅读理解
7. 贪吃蛇记忆 — 多任务处理+空间记忆

**技术实现**:
- 纯 Python 标准库，零外部依赖
- ANSI 终端渲染
- 非阻塞键盘输入
- 递归回溯迷宫生成
- 完整加密/解密工具集
