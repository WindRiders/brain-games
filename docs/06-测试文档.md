# Brain Games — 测试文档

## 1. 测试策略

### 1.1 测试原则
- **纯逻辑可单元测试**：迷宫生成、加密/解密、评分计算等纯函数
- **交互游戏需手动测试**：键盘输入、终端渲染等需人工验证
- **Mock 终端组件**：Renderer 和 InputManager 在单元测试中使用 Mock

### 1.2 测试工具
- pytest：测试框架
- 标准库 `unittest.mock`：Mock 对象

### 1.3 测试覆盖率目标
- 工具函数：100%
- 引擎核心：80%+
- 游戏逻辑：70%+
- UI 组件：不纳入覆盖率（纯渲染）

## 5. 运行测试

```bash
# 运行所有测试
python3 -m pytest tests/ -v

# 运行特定测试文件
python3 -m pytest tests/test_maze_gen.py -v

# 运行特定测试
python3 -m pytest tests/test_crypto.py::TestCaesarCipher::test_encrypt_shift3 -v

# 显示覆盖率（如安装 pytest-cov）
python3 -m pytest tests/ --cov=src --cov-report=term-missing

# 快速测试（跳过慢速测试）
python3 -m pytest tests/ -v --ignore=tests/test_games.py
```

## 6. 已知限制

| 限制 | 原因 | 影响 |
|------|------|------|
| 键盘输入延迟 | 终端行缓冲 | 极少数终端可能有 10-50ms 延迟 |
| Emoji 兼容性 | 字体/终端差异 | 部分 Emoji 可能显示为方框 |
| Windows CMD 颜色 | 旧版 CMD 不支持 ANSI | Windows 10+ 正常，旧版降级 |
| 节拍精度 | Python time.sleep 精度 | 节奏大师 BPM 可能有 ±5ms 偏差 |
