# Brain Games — 交互设计文档

## 1. 整体交互原则

### 1.1 设计原则
- **键盘优先**：所有操作通过键盘完成，无需鼠标
- **一致性**：所有游戏共享统一的退出(Help/Q)、帮助(H)操作
- **即时反馈**：每次按键操作都有视觉/文字反馈
- **容错设计**：关键操作前二次确认，误操作可撤销

### 1.2 通用按键映射

| 按键 | 功能 | 适用范围 |
|------|------|---------|
| `Q` / `Esc` | 退出当前游戏，返回主菜单 | 所有游戏 |
| `H` | 显示/隐藏帮助信息 | 所有游戏 |
| `Enter` | 确认/提交输入 | 输入类游戏 |
| `1-9` | 数字选择/操作 | 打地鼠等 |
| 方向键 / WASD | 移动控制 | 移动类游戏 |

```

用户输入
  ├─ 1-7 → 进入对应游戏

  ├─ R   → 确认重置？(Y/N) → Y:清空分数 / N:返回
```

## 6. 错误处理交互

### 6.1 无效输入
```
  ❌ 无效的输入，请重试。
```
不消耗任何游戏资源，仅提示后重新等待。

### 6.2 终端太小
```
  ⚠️ 终端窗口太小！请将窗口调整为至少 80×24
  当前大小：60×15
  按任意键继续尝试...
```

### 6.3 键盘不支持
```
  ⚠️ 检测到按键响应延迟，建议使用以下终端：
  Windows: Windows Terminal / WSL
  macOS: iTerm2 / Terminal.app
  Linux: GNOME Terminal / Konsole
  按任意键继续...
```
