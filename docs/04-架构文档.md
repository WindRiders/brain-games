## 3. 核心类设计

### 3.1 游戏基类 (BaseGame)

```
┌─────────────────────────────────┐
│           BaseGame               │
├─────────────────────────────────┤
│ - name: str                      │
│ - difficulty: str                │
│ - score: int                     │
│ - running: bool                  │
│ - high_scores: dict              │
├─────────────────────────────────┤
│ + setup()                        │
│ + game_loop()                    │
│ + handle_input(key) -> bool      │
│ + update()                       │
│ + render()                       │
│ + get_score() -> int             │
│ + save_score()                   │
│ + show_help()                    │
│ + cleanup()                      │
└─────────────────────────────────┘
```

所有游戏继承此基类，实现 `setup()`, `game_loop()`, `handle_input()`, `update()`, `render()` 方法。

### 3.2 输入管理器 (InputManager)

```
┌─────────────────────────────────┐
│          InputManager            │
├─────────────────────────────────┤
│ - _fd                            │
│ - _old_settings                  │
├─────────────────────────────────┤
│ + init()                         │
│ + get_key() -> str               │
│ + get_key_nonblocking() -> str|None │
│ + cleanup()                      │
└─────────────────────────────────┘
```

使用 `termios` (Linux/macOS) 或 `msvcrt` (Windows) 实现非阻塞键盘输入。

### 3.3 渲染引擎 (Renderer)

```
┌─────────────────────────────────┐
│           Renderer               │
├─────────────────────────────────┤
│ - buffer: list[str]              │
│ - color_support: bool            │
│ - width: int                     │
│ - height: int                    │
├─────────────────────────────────┤
│ + clear()                        │
│ + move_cursor(x, y)              │
│ + draw_text(x, y, text, color)  │
│ + draw_box(x, y, w, h, text)    │
│ + draw_progress(pct, width)      │
│ + flush()                        │
│ + shake_screen(times=3)          │
│ + flash(color, duration)         │
└─────────────────────────────────┘
```

### 3.4 计时器 (GameTimer)

```
┌─────────────────────────────────┐
│           GameTimer              │
├─────────────────────────────────┤
│ - start_time: float              │
│ - elapsed: float                 │
│ - paused: bool                   │
│ - callbacks: list                │
├─────────────────────────────────┤
│ + start()                        │
│ + pause()                        │
│ + resume()                       │
│ + stop()                         │
│ + get_elapsed() -> float         │
│ + on_tick(callback, interval)    │
└─────────────────────────────────┘
```

### 3.5 状态机 (GameState)

```
┌─────────────────────────────────┐
│           GameState              │
├─────────────────────────────────┤
│ - states: dict                   │
│ - current: str                   │
├─────────────────────────────────┤
│ + add_state(name, enter, update, │
│             render, exit)        │
│ + switch(name)                   │
│ + update()                       │
│ + render()                       │
└─────────────────────────────────┘
```

状态流转：
```
  MENU → DIFFICULTY_SELECT → HELP → PLAYING → PAUSED
                                                   ↓
    MENU ← GAME_OVER ← PLAYING
```

### 3.6 评分管理器 (ScoreManager)

```
┌─────────────────────────────────┐
│         ScoreManager             │
├─────────────────────────────────┤
│ - scores_file: Path              │
│ - scores: dict                   │
├─────────────────────────────────┤
│ + load()                         │
│ + save()                         │
│ + get_high_score(game, diff)     │
│ + set_high_score(game, diff, sc) │
│ + show_all() -> str              │
│ + reset()                        │
└─────────────────────────────────┘
```

存储格式 (`~/.brain_games/scores.json`):
```json
{
  "maze": {"easy": 850, "normal": 1200, "hard": 2100},
  "math_dodge": {"easy": 600, "normal": 950, "hard": 1500},
  ...
}
```

## 4. 数据流

```
用户按键
  ↓
InputManager.get_key()
  ↓
Game.handle_input(key)
  ↓
  ├─ 更新游戏状态
  ├─ 更新得分
  └─ 检查游戏结束条件
  ↓
Game.update()
  ↓
Game.render()
  ↓
Renderer.flush() → 终端显示
```

## 7. 启动流程

```
main.py 启动
  ↓
初始化 Renderer（检测终端能力）
  ↓
初始化 InputManager
  ↓
初始化 ScoreManager（加载历史分数）
  ↓
显示主菜单 (MainMenu)
  ↓
用户选择游戏编号
  ↓
选择难度
  ↓
显示帮助
  ↓
实例化对应游戏类
  ↓
调用 game.game_loop()
  ↓
游戏结束 → 显示得分 → 保存分数
  ↓
返回主菜单
```

## 8. 技术选型

| 组件 | 技术选择 | 原因 |
|------|---------|------|
| 终端渲染 | ANSI 转义序列 | 跨平台兼容性好 |
| 键盘输入 | termios/curses (Linux) / msvcrt (Windows) | 低延迟、非阻塞 |
| 迷宫生成 | 递归回溯算法 | 保证有解、实现简单 |
| 数据存储 | JSON 文件 | 轻量、无需数据库 |
| 测试 | pytest | Python 标准测试框架 |
| 依赖 | 仅 Python 标准库 | 零外部依赖，即开即用 |

## 9. 跨平台兼容

```python
# 平台检测
import sys
import platform

IS_WINDOWS = platform.system() == "Windows"

# 键盘输入
if IS_WINDOWS:
    import msvcrt  # Windows 非阻塞输入
else:
    import termios  # Linux/macOS 终端控制
    import tty

# 终端尺寸
if IS_WINDOWS:
    import shutil
    columns, lines = shutil.get_terminal_size()
else:
    import os
    columns, lines = os.get_terminal_size()
```
