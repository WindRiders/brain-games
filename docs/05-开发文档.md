## 2. 编码规范

### 2.1 命名约定
- 类名：PascalCase (`MemoryMazeGame`)
- 函数/方法：snake_case (`handle_input`, `get_score`)
- 常量：UPPER_SNAKE_CASE (`BG_YELLOW`, `RESET`)
- 私有成员：前缀下划线 (`_old_settings`)
- 文件名：snake_case (`maze_gen.py`)

### 2.2 代码风格
- 缩进：4 空格
- 行宽：最多 120 字符
- 文件编码：UTF-8
- 类型注解：所有公开方法必须包含类型注解

### 2.3 文档字符串
```python
def generate_maze(width: int, height: int) -> list[list[int]]:
    """使用递归回溯算法生成迷宫。

    Args:
        width: 迷宫宽度（单元格数）
        height: 迷宫高度（单元格数）

    Returns:
        二维列表，0=通道，1=墙壁

    Raises:
        ValueError: 当 width 或 height 为偶数时
    """
```

## 3. 开发指南

### 3.1 添加新游戏

1. 在 `src/games/` 下创建游戏文件 `new_game.py`
2. 继承 `BaseGame` 类
3. 实现以下方法：

```python
from src.engine.base import BaseGame

class NewGame(BaseGame):
    """新游戏实现。"""

        """初始化游戏状态、根据难度设置参数。"""
        pass

    def game_loop(self) -> None:
        """游戏主循环：处理输入→更新→渲染。"""
        pass

    def handle_input(self, key: str) -> bool:
        """处理按键输入，返回 False 表示退出游戏。"""
        pass

    def update(self) -> None:
        """更新游戏逻辑（位置、状态、计时等）。"""
        pass

    def render(self) -> None:
        """渲染游戏画面到终端。"""
        pass

    def get_score(self) -> int:

        pass
```

4. 在 `src/games/__init__.py` 中注册游戏
5. 在 `GAME_REGISTRY` 中添加条目
6. 编写对应测试

### 3.2 渲染最佳实践

```python
# 推荐：批量构建渲染内容，一次性输出
def render(self) -> None:
    lines = []
    lines.append(self._build_header())
    lines.append(self._build_game_area())
    lines.append(self._build_footer())
    self.renderer.render("\n".join(lines))

# 避免：逐行输出（会导致闪烁）
def render_bad(self) -> None:
    print(line1)  # ❌ 每次 print 都可能闪烁
    print(line2)
    print(line3)
```

### 3.3 输入处理最佳实践

```python
# 非阻塞输入：游戏循环中持续检测
def game_loop(self) -> None:
    while self.running:
        key = self.input_manager.get_key_nonblocking()
        if key:
            if not self.handle_input(key):
                break
        self.update()
        self.render()
        time.sleep(1.0 / self.fps)
```

## 4. 关键算法

### 4.1 迷宫生成（递归回溯）

```python
def generate_maze(width: int, height: int) -> list[list[int]]:
    """
    递归回溯算法生成完美迷宫（任意两点间有且仅有一条路径）。

    步骤：
    1. 初始化全为墙壁的网格
    2. 从起点(1,1)开始，标记为通道
    3. 随机选择一个未访问的邻居
    4. 打通当前格与邻居之间的墙壁
    5. 递归处理邻居
    6. 没有未访问邻居时回溯

    保证：
    - 迷宫一定有解
    - 没有环路
    - 所有通道连通
    """
```

### 6.2 src/engine/base.py — 游戏基类

```python
class BaseGame(ABC):
    """所有游戏的抽象基类。"""

    def __init__(self, difficulty: str, renderer, input_manager, score_manager):
        self.difficulty = difficulty
        self.renderer = renderer
        self.input = input_manager
        self.scores = score_manager
        self.score = 0
        self.running = False

    @abstractmethod
    def setup(self) -> None: ...

    @abstractmethod
    def game_loop(self) -> None: ...

    @abstractmethod
    def handle_input(self, key: str) -> bool: ...

    @abstractmethod
    def update(self) -> None: ...

    @abstractmethod
    def render(self) -> None: ...

    def get_score(self) -> int: ...
    def save_score(self) -> None: ...
    def show_help(self) -> None: ...
```

```python
import time

# FPS 监控
frame_times = []
def track_fps():
    frame_times.append(time.time())
    if len(frame_times) > 60:
        frame_times.pop(0)
        avg = len(frame_times) / (frame_times[-1] - frame_times[0])
        logger.debug(f"FPS: {avg:.1f}")
```
