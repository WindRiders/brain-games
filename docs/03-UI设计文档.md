# Brain Games — UI 设计文档

## 1. 整体视觉风格

### 1.1 设计理念
- **终端原生**：纯 ASCII/ANSI 字符渲染，不依赖图形库
- **暗黑主题**：终端默认黑色背景上的彩色文字
- **层次分明**：通过边框、颜色、间距区分信息层级
- **一致性**：统一的边框风格、配色方案、间距规范

### 1.2 配色方案

```
主色调：
  标题/边框    — 亮青色   (Cyan)     \033[96m
  得分/分数    — 亮黄色   (Yellow)   \033[93m
  成功/正确    — 亮绿色   (Green)    \033[92m
  失败/错误    — 亮红色   (Red)      \033[91m
  玩家/角色    — 亮白色   (White)    \033[97m
  墙壁/障碍    — 灰色     (Gray)     \033[90m
  通道/背景    — 默认终端色
  高亮/选中    — 亮品红   (Magenta)  \033[95m
  提示信息     — 亮蓝色   (Blue)     \033[94m

样式修饰：
  粗体         \033[1m
  下划线       \033[4m
  闪烁         \033[5m  (倒计时等紧急信息)
  反色         \033[7m  (选中项)
  重置         \033[0m
```

### 1.3 边框样式规范

```
主框架边框（游戏主体）：
  ═══════════════════════════════════════════════
  ║                                             ║
  ║                                             ║
  ═══════════════════════════════════════════════

子面板边框（提示框、帮助面板）：
  ┌─────────────────────────────────────────────┐
  │                                             │
  │                                             │
  └─────────────────────────────────────────────┘

分隔线：
  ─────────────────────────────────────────────

表格分隔：
  ─────────────────────────────────────────────

角落装饰：
  左上 ┌   右上 ┐
  左下 └   右下 ┘
```

### 1.4 间距规范

```
面板内边距：左右各 2 字符
行间距：空行 = 1 行
标题间距：标题上下各 1 空行
信息分组：不同信息组之间空 1 行
```

## 2. 通用 UI 组件

### 2.1 标题栏

```
  ═══════════════════════════════════════════════
          ★ 标 题 文 字 ★
  ═══════════════════════════════════════════════
```
- 宽度：55 字符（含装饰线）
- 居中对齐
- 青色边框 + 黄色标题

### 2.2 得分栏（顶部状态栏）

```
  得分：1,250   关卡：3/10   ❤❤❤   ⏱ 45s
```
- 右对齐或居中
- 黄色分数 + 白色信息
- 每局游戏持续显示

### 2.3 进度条

```
  进度：████████░░░░░░░░░░░░  40%
  时间：████████████░░░░  12s
  生命：███████████████░  85%
```
- 总宽度 20 字符
- 填充字符：`█` (U+2588)
- 空白字符：`░` (U+2591)
- 颜色：>60% 绿色，30-60% 黄色，<30% 红色

### 2.4 提示/消息框

```
  ┌─ ⚠ 提示 ───────────────────────────────────┐
  │  这是提示消息内容                            │
  │  可以有多行                                  │
  └────────────────────────────────────────────┘
```

### 2.5 按钮（文字表示）

```
  [开始游戏]    [查看帮助]    [退出]
```
- 方括号包围
- 选中状态用反色 `[开始游戏]` → `\033[7m[开始游戏]\033[0m`

## 3. 游戏专属 UI

### 3.1 G1 记忆迷宫

#### 迷宫渲染规范
```
字符映射：
  墙壁    █ (U+2588)  灰色
  通道    · (U+00B7)  深灰色
  起点    S (亮绿色)  仅记忆阶段可见
  终点    E (亮黄色)  仅记忆阶段可见
  玩家    @ (亮白色)  行走阶段可见
  路径迹  * (亮品红)  玩家走过的路径

记忆阶段边框：
  ┌──────────────────────┐
  │  ★ 记忆阶段 ★        │
  │  剩余：12s ██████░░  │
  │                      │
  │  [迷宫内容]          │
  │                      │
  │  S=起点 E=终点       │
  └──────────────────────┘

行走阶段边框：
  ┌──────────────────────┐
  │  ★ 凭记忆走出去 ★    │
  │  得分：850 撞墙：1   │
  │                      │
  │  [隐藏迷宫内容]      │
  │                      │
  │  @=你 WASD移动       │
  └──────────────────────┘
```

#### 迷宫尺寸
```
简单 5x5：  内部渲染宽度 11 (2*5+1)，高度 5
普通 8x8：  内部渲染宽度 17 (2*8+1)，高度 8
困难 12x12：内部渲染宽度 25 (2*12+1)，高度 12
```
注：墙壁用双字符宽度渲染以保持比例

### 3.2 G2 弹幕大脑

#### 弹幕渲染
```
弹幕格式：
  [3+7=? 9]    → 红色（错误答案）
  [3+7=? 10]   → 绿色（正确答案，但玩家不知道）
  [3+7=? 11]   → 红色（错误答案）

玩家角色：
  @             → 亮白色，最底行

碰撞反馈：
  ✓ +100       → 绿色，角色位置上方闪烁1秒
  ✗ -50        → 红色，角色位置上方闪烁1秒
  ⏰ -30       → 黄色，屏幕中央闪烁1秒

场地：
  宽度 50 字符
  高度 20 行
  玩家仅在最后一行移动
```

### 3.4 G4 节奏大师

#### 轨道渲染
```

  │                           [  D  ]        ││
  │                    [  A  ]               ││
  │             [  D  ]                      ││

  ✗ Miss ✗        (红色)

  右上角：Combo: 12 🔥 (连续5以上加火焰emoji)
```

## 4. 动画与特效

### 4.1 闪烁效果
```
实现：通过交替显示/隐藏文本实现
频率：0.5秒切换
用于：倒计时 < 3秒、紧急提示
```

### 4.2 屏幕震动（撞墙等）
```
实现：将内容左右偏移 1-2 字符，连续 3 次
用于：撞墙反馈、答错反馈
```

### 4.3 渐变消失（记忆阶段结束）
```
实现：逐步将字符替换为空格，从下往上
用于：迷宫记忆阶段结束
```

### 4.4 打字机效果
```
实现：逐字符输出，间隔 20ms
用于：故事场景描述
```

## 5. 终端适配

### 5.1 最小终端尺寸
```
宽度：80 字符
高度：24 行
低于此尺寸显示警告并建议调整
```

### 5.2 彩色终端检测
```
检测 NO_COLOR 环境变量
检测 TERM 是否支持彩色
不支持时自动降级为纯 ASCII 无边框
```

### 5.3 Emoji 降级
```
终端不支持 emoji 时：
  ❤ → ♥
  🔨 → [锤]
  🐹 → [鼠]
  🐍 → [蛇]
  🔥 → *
  ⚠ → [!]
  ✓ → OK
  ✗ → X
```
